## ✨ Features
- **User Authentication:** Secure Signup and Login using JWT (JSON Web Tokens).
- **Task Management:** Create, Read, Update, and Delete (CRUD) tasks.
- **Protected Routes:** Only authenticated users can access their dashboard.
- **Responsive UI:** Fully optimized for mobile and desktop using Tailwind CSS.
- **Database Integration:** Real-time data storage with MongoDB Atlas.

---

## 🛠️ Tech Stack
- **Frontend:** React.js, Vite, Tailwind CSS, Axios.
- **Backend:** Node.js, Express.js.
- **Database:** MongoDB Atlas.
- **Deployment:** Railway (Backend) & Vercel (Frontend).
